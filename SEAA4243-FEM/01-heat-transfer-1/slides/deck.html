Block 1 · the idea that organises the course

FEM is “nothing”: a tool that solves a differential equation

1 · Get the DE

Energy balance + Fourier’s law → a PDE in T(x, y)

2 · Discretise with FEM

Shape functions + Galerkin → [k]{T̂}ᵀ = {r}

3 · Solve

Assemble, impose T̄, solve, post-process

FEM can be “everything”

Heat, seepage, stress, vibration, fluid flow — the same machinery solves all of them. That is why it is worth learning well.

…and FEM can be “nothing”

It is only a way to turn a continuous PDE into simultaneous algebraic equations in matrix form. Nothing is new in the physics.

Finite difference, finite volume, meshless and isogeometric methods share the same goal; they differ in how the discretisation is done.

Block 1 · where civil engineers meet conduction

The same PDE appears across civil engineering

Mass concrete

Heat of hydration in dams, rafts and pile caps: the temperature rise and the gradient between core and surface drive early-age cracking.

Fire engineering

Temperature rise in steel sections and tunnel linings decides when strength is lost; the input is a 2D conduction model of the section.

Pavements and decks

Daily thermal gradients through a bridge deck or a pavement slab produce stresses that codes make us check.

Ground and geothermal

Ground freezing, energy piles and buried pipelines are conduction problems in soil — and seepage uses the same equation.

Block 3 · two kinds of condition · text (2.15)–(2.16)

Either T or the normal flux is known at every boundary point

Dirichlet · essential · temperature specified

(2.16)

e.g. a face held at a fixed temperature by a fluid bath or the ground.

(2.15)

Block 3 · rectangular domains

On a rectangle the normal is a coordinate axis, so (2.15) collapses to one term

vertical edges

horizontal edges

insulated

Watch out

Sign: qb = k ∂T/∂n is positive when heat enters. On the right edge n = (+1, 0): an inward flux makes ∂T/∂x > 0 there, so qb > 0 — while the flux vector component qx = −k ∂T/∂x is negative. Two different symbols; keep them apart.

Why

Insulated = adiabatic = zero normal flux. It is a Neumann condition with qb = 0, not a Dirichlet condition.

Block 4 · degrees of freedom · text Fig. 2.2

A rectangle a × b, nodes numbered anticlockwise

Notation

  • T̂i (hat): the nodal temperature at node i — a number, the unknown we solve for.
  • T(x, y): the temperature field inside the element — a function.
  • Ni(x, y): the shape function that carries the influence of node i into the field.
  • Local coordinates: origin at node 1, x along the bottom edge, y along the left edge.

Watch out

Numbering is anticlockwise. Reverse it and the matrix entries the next session come out in the wrong places.

SEAA 4243 · 2D Heat Transfer — Part 1

27

Block 4 · assume a polynomial · text (2.17)

Four nodes, four coefficients: 1, x, y and xy

(2.17)

Why these four monomials?

  • Four nodal values can fix exactly four coefficients.
  • 1, x, y give a plane; xy is the lowest-order term that is symmetric in x and y.
  • x² without y² would favour one direction — the choice is geometrically balanced.
  • Along any edge (x = const or y = const) the polynomial is linear in the other variable.

Pascal triangle · text Fig. 2.4

1

x      y

x²    xy    y²

x³   x²y   xy²   y³

4-node element: the four maroon terms. 8-node element: all terms down to x²y and xy² (Block 5).

Why

“Bilinear”: linear in x for fixed y and linear in y for fixed x — but not a plane, because of the xy term.

Block 4 · solve for the coefficients · text (2.19)

Four coefficients in terms of the four nodal temperatures

(2.19)

Read them physically

  • a1: the value at the origin (node 1).
  • a2: the slope along the bottom edge, (T̂2 − T̂1)/a.
  • a3: the slope along the left edge, (T̂4 − T̂1)/b.
  • a4: the “twist” — how the x-slope changes with y.

Check with a uniform field

Put T̂1 = T̂2 = T̂3 = T̂4 = T0: then a1 = T0 and a2 = a3 = a4 = 0, so T = T0 everywhere. The element reproduces a constant exactly.

Same functions, new coordinates

Block 4 · three properties you can check in 30 seconds

Kronecker delta, partition of unity, linear edges

1 · Kronecker delta

So T at node j equals T̂j: the nodal unknowns really are nodal temperatures.

2 · Partition of unity

A uniform temperature is reproduced exactly — the test we did on the coefficients.

3 · Linear along each edge

C⁰ continuity follows: the neighbouring element shares this edge’s two nodes and its straight line.

Block 4 · from one element to the mesh

One nodal value lifts one tent

1D: φᵢ is a hat over the two elements that share node i.

2D: a tent over every element sharing the node.

Why

Each element that touches node i adds one face of its tent. That is why T is continuous across element edges, and why node i couples only to its neighbours: the global matrix is sparse (Heat Transfer Part 2).

Block 5 · differentiate the approximation

Gradient = derivative matrix × nodal temperatures

from (2.21)

Why

∂Ni/∂x depends on y only and ∂Ni/∂y on x only — the gradient varies inside the element, though each component is constant along one direction.

Check

Fourier’s law in matrix form is the post-processing formula

Block 6 · the MATLAB skeleton follows the pipeline

Thirty lines: local matrix, assembly, boundary conditions, solve

% Local conductance matrix (text §2.3.1)

a = L/Nx; b = H/Ny;

s1 = b*kx/(3*a) + a*ky/(3*b);

s2 = -b*kx/(3*a) + a*ky/(6*b);

s3 = -b*kx/(6*a) - a*ky/(6*b);

s4 = b*kx/(6*a) - a*ky/(3*b);

k = [s1 s2 s3 s4; s2 s1 s4 s3; s3 s4 s1 s2; s4 s3 s2 s1];

fQ = a*b*Q/4*[1; 1; 1; 1]; % heat generation

% Assembly by connectivity, element 1 = nodes [1 2 5 4]

K([1 2 5 4],[1 2 5 4]) = K([1 2 5 4],[1 2 5 4]) + k;

F([1 2 5 4]) = F([1 2 5 4]) + fQ;

% Impose T = To on known dofs, solve the rest

dof_k = [1 4 7 8 9]; T(dof_k) = To;

F = F - K(:,dof_k)*T(dof_k);

dof_u = setdiff(1:ndof, dof_k);

T(dof_u) = K(dof_u,dof_u) \ F(dof_u);

Read the code against the steps

  • Lines 2–8: step 5, the element matrix and load from closed-form integrals (we derive s1…s4 the next session).
  • Lines 11–12: step 6, assembly — the connectivity list [1 2 5 4] is the element’s global node numbers.
  • Lines 15–18: step 6, essential conditions by row–column elimination; step 7, solve with the backslash operator.

Check

Bring a laptop with MATLAB the next session; we trace this code line by line on the 2 × 2 mesh.
