# 2D Heat Transfer — Part 2
Galerkin dan integration by parts menukar PDE kepada [k]{T̂}ᵀ = {q} + {b}; matrix element dalam closed form, assembly mengikut connectivity, temperature yang diketahui dikenakan, dan plat dalam teks diselesaikan secara tangan dan disemak dengan mesh halus.

[start-outcomes] Selepas bahagian ini, anda sepatutnya boleh
1. Menggunakan Galerkin weighted residual method dan integration by parts untuk memperoleh [k]{T̂}ᵀ = {q} + {b} dan menerangkan maksud setiap term.
2. Menilai conductance matrix [k] dan load vector {q} dan {b} bagi 4-node rectangular element dalam closed form.
3. Meng-assemble matrix element ke dalam sistem global dengan connectivity table dan mengenakan Dirichlet condition melalui row–column elimination.
4. Menyelesaikan masalah kecil secara tangan, post-process temperature dan flux pada satu titik, dan menilai hasilnya berbanding mesh yang di-refine.

Term Nama Apa yang dikandunginya
[k] conductance matrix bahan dan geometri element; simetri; 4 × 4
{q} source vector haba yang dijana di dalam element, dikongsi antara node-nya
{b} boundary vector haba yang masuk melalui tepi dengan flux diketahui; sifar pada tepi insulated; dibuang bersama persamaan pada tepi Dirichlet
Tepi mana yang menyumbang kepada {b}? Bagi plat dalam teks (atas dan kiri pada 0 °C, kanan dan bawah insulated): tiada. Tepi insulated ada q_b = 0, dan pada dua tepi Dirichlet flux yang tidak diketahui mendarab N_i bagi node yang persamaannya kita buang apabila T dikenakan. Flux di situ boleh diperoleh semula kemudian, seperti support reaction.
Isi penting:
- Galerkin: weighted residual dengan shape function sebagai weight function; integration by parts merendahkan peringkat derivative dan mendedahkan natural condition.
- [k]{T̂}ᵀ = {q} + {b} = {r}: conductance matrix, source vector, boundary vector.
- Satu 4-node element memberi 4 persamaan; mesh 2 × 2 memberi 9, dan 4 tinggal selepas T dikenakan pada 5 node.

[notes-n6] Nota 6. Skrip, tugasan dan apa yang seterusnya
Skrip ini ialah pipeline dalam tiga puluh baris. Baca ia berpandukan tujuh langkah dan setiap blok ada namanya.
% Local conductance matrix (text §2.3.1)
a = L/Nx; b = H/Ny;
s1 = b*kx/(3*a) + a*ky/(3*b);
s2 = -b*kx/(3*a) + a*ky/(6*b);
s3 = -b*kx/(6*a) - a*ky/(6*b);
s4 = b*kx/(6*a) - a*ky/(3*b);
k = [s1 s2 s3 s4; s2 s1 s4 s3; s3 s4 s1 s2; s4 s3 s2 s1];
fQ = a*b*Q/4*[1; 1; 1; 1]; % heat generation
% Assembly by connectivity (conn(e,:) = global nodes of element e)
for e = 1:Ne, c = conn(e,:); K(c,c) = K(c,c) + k; F(c) = F(c) + fQ; end
% Essential conditions: known nodes removed, their columns moved to the right
free = setdiff(1:n, fixed); T = zeros(n,1); T(fixed) = Tbar;
T(free) = K(free,free) \ (F(free) - K(free,fixed)*T(fixed));
% Post-processing: element, local coordinates, interpolation
e = find_element(x, y); xl = x - X(conn(e,1)); yl = y - Y(conn(e,1));
N = [(a-xl)*(b-yl), xl*(b-yl), xl*yl, yl*(a-xl)]/(a*b); Tp = N*T(conn(e,:));

[glossary-residual] Glosari: residual
residual: Apa yang tinggal apabila approximation digantikan ke dalam PDE; sifar hanya untuk penyelesaian tepat.

[glossary-weighted-residual] Glosari: weighted residual
weighted residual: Residual didarab dengan weight function dan di-integrate; disamakan dengan sifar untuk mendapat satu persamaan setiap weight function.

[glossary-galerkin-method] Glosari: Galerkin method
Galerkin method: Weighted residual dengan shape function sebagai weight function; memberi [k] yang simetri.

[glossary-integration-by-parts-green-s-theorem] Glosari: integration by parts · Green’s theorem
integration by parts · Green’s theorem: Memindahkan satu derivative dari T kepada weight function dan menghasilkan boundary term; dalam 2D integral luas ditukar dengan integral sempadan.

[glossary-weak-form] Glosari: weak form
weak form: Pernyataan ter-integrate dengan derivative lebih rendah yang menjadi asal persamaan finite element.

[glossary-conductance-matrix-k] Glosari: conductance matrix [k]
conductance matrix [k]: 4 × 4, simetri, daripada ∫{N}ᵀ{∂}[E]{∂}ᵀ{N} dA; analog haba bagi stiffness. Unit W K^{−1} per unit ketebalan.

[glossary-s-1-s-4] Glosari: s_1 …s_4
s_1 …s_4: Empat entri berbeza [k] bagi segi empat tepat, (2.49); s_1 pepenjuru, s_2 sisi mendatar, s_4 sisi menegak, s_3 pasangan pepenjuru.

[glossary-source-vector-q] Glosari: source vector {q}
source vector {q}: Nodal load daripada haba yang dijana di dalam element, q_h ab/4 setiap satu bagi source seragam.

[glossary-boundary-vector-b] Glosari: boundary vector {b}
boundary vector {b}: Nodal load daripada flux yang diketahui pada satu tepi, q_b ℓ/2 pada setiap satu daripada dua node tepi itu.

[glossary-row-sum-check] Glosari: row-sum check
row-sum check: Setiap baris [k] berjumlah sifar kerana temperature seragam tidak mengalirkan haba.

[glossary-connectivity-table] Glosari: connectivity table
connectivity table: Bagi setiap element, nombor node global-nya mengikut susunan local lawan jam.

[glossary-assembly-scatter-add] Glosari: assembly · scatter-add
assembly · scatter-add: K_{IJ} += k_{ij} dengan I, J dibaca daripada connectivity table; sama untuk {R}.

[glossary-global-system-k-t-r] Glosari: global system [K]{T} = {R}
global system [K]{T} = {R}: Semua element di-assemble; singular sehingga sekurang-kurangnya satu temperature ditetapkan.

[glossary-row-column-elimination] Glosari: row–column elimination
row–column elimination: Mengenakan T̄ yang diketahui: pindahkan lajurnya × T̄ ke sebelah kanan, buang baris dan lajur itu.

[glossary-reduced-system] Glosari: reduced system
reduced system: Persamaan yang tinggal untuk temperature yang tidak diketahui selepas yang diketahui dibuang.

[glossary-struck-rows-energy-balance] Glosari: struck rows · energy balance
struck rows · energy balance: Baris node yang diketahui, dinilai selepas itu, memberi aliran haba di situ; jumlahnya mengimbangi haba yang dimasukkan.

[glossary-local-coordinates] Glosari: local coordinates
local coordinates: Kedudukan diukur dari node local 1 sesuatu element; itulah yang mesti digunakan untuk menilai N_i .

[glossary-post-processing] Glosari: post-processing
post-processing: Segala yang dikira daripada penyelesaian node: T pada satu titik, flux, titik paling panas, aliran haba.

[glossary-mesh-refinement-convergence] Glosari: mesh refinement · convergence
mesh refinement · convergence: Mengulang penyelesaian pada mesh yang lebih halus sehingga jawapan berhenti berubah; element bilinear converge sebagai h².

[glossary-relative-error] Glosari: relative error
relative error: (T_{mesh} − T_{ref} )/T_{ref} ; kira-kira +5% bagi mesh 2 × 2 plat dalam teks.

[glossary-patch-test] Glosari: patch test
patch test: Field yang mampu diwakili element dengan tepat (di sini T linear) mesti dihasilkan semula dengan tepat pada mana-mana mesh.

[glossary-symmetry] Glosari: symmetry
symmetry: Geometri, bahan, load dan boundary condition yang sama tentang satu garis memberi temperature yang sama pada node cermin; garis simetri tidak membawa haba merentasinya.
