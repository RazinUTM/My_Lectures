Same equations, same checks, other codes

Code_Aster (open-source FE), solid plate heated from below, shown in Gmsh. preCICE tutorials, “Flow over a heated plate, steady state”, LGPL-3.0.

ANSYS MAPDL, plate with two faces at 5 and 100 °C. PyMAPDL documentation, “Basic thermal analysis”, © ANSYS, Inc., MIT licence.

Why

Left: the field your Heat Transfer Part 2 script would produce for that plate — hot boundary below, cooled boundary above, contours parallel to the edges.

Check

Right: no source and two fixed faces give a linear T. Every FE code must reproduce it exactly, because the four-node element contains 1, x and y: a quick check of any new model.

Two independent codes, the same equation. The MAPDL example is a useful sanity check students can repeat in the ANSYS demo: with no heat generation and two faces at fixed temperature, the solution is linear and any mesh reproduces it to machine precision (a patch test). If it does not, the model is wrong, not the mesh.
