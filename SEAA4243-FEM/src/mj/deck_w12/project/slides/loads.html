Block 3 · edge traction → nodal loads · text (3.37), (3.45)

A uniform traction on edge 2–3 loads v₂ and v₃ equally

Why

Qy = −5000 N m⁻¹ (downward), b = 1 m: −2500 N at v2 (dof 4) and v3 (dof 6) of elements 2 and 4. Only elements with an edge on the loaded boundary get a {b}.

(3.45)

Body force, e.g. self-weight: a quarter of the element weight at each node, in the v-dofs.

The text gives q_y as a line load in kN/m along the edge (force per unit length of the edge for the whole thickness). Per unit area it would be q_y/t; multiplied by t in the integral it returns to q_y. Self-weight is ignored in the text’s example; the formula is shown so students can add it in the project.
