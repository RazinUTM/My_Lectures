Build the first mesh of your project model and verify it

Do

  • Open the model plan returned from Plane Stress Part 3; build steps 1–6 of the checklist.
  • Solve on the coarse mesh; read the reaction probe first; compare with the applied load.
  • Write the hand estimate (beam theory, statics, or a stress-concentration factor) next to the FE value.
  • If both agree within a factor of 2, run the second mesh; if not, find the input error before refining.
  • Save as [group]_project.wbpj; screenshot the reaction probe and the result.

Lecturer visits — be ready to answer

  • What is free and what is fixed, and why?
  • What is your hand check?
  • Where will the stress maximum be, and is it a singularity?
