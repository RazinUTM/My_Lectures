Fixed Support, an edge force, plane stress with thickness — then the mesh of Plane Stress Part 2

Watch out

First number to read is not the deflection: it is the reaction. +10 000 N in Y, moment 40 000 N m, or something is wrong.

Build order (click path in the notes)

  • Static Structural → Engineering Data: new material, Isotropic Elasticity E = 2 × 10⁸ Pa, ν = 0.33.
  • Geometry (2D): 4 m × 2 m surface body; in Mechanical: 2D Behavior = Plane Stress, Thickness = 0.01 m.
  • Mesh: Face Meshing; Edge Sizing 2 divisions on all edges; Element Order Linear.
  • Fixed Support on the left edge; Force on the right edge, components, Y = −10 000 N.
  • Solve → Directional Deformation (Y); probe at the top-right vertex; Force Reaction on the Fixed Support.

Script: Toolbox → Static Structural; Geometry → Analysis Type 2D; sketch 4 × 2 m rectangle, Surfaces From Sketches; Mechanical → Geometry → 2D Behavior: Plane Stress; surface body → Thickness 0.01 m; assign material. Mesh → Face Meshing; Edge Sizing on the four edges: Number of Divisions 2 (set Behavior: Hard); Mesh details → Element Order: Linear; Generate → 4 elements, 9 nodes. Static Structural → Fixed Support (left edge); Force (right edge) → Define By: Components, Y = −10000 N. Solve. Insert Directional Deformation Y; Deformation Probe at the top-right vertex; Force Reaction probe (Boundary Condition: Fixed Support), and a Moment Reaction probe. Element Control note: Mechanical may apply an enhanced-strain formulation to linear elements (‘Program Controlled’). If the 2 × 2 linear result is much better than 0.131 m, say so and show Element Control: Manual with full integration for comparison; either way, discuss, do not hide.
