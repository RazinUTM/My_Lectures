Watch out

Sign: qb = k ∂T/∂n is positive when heat enters. On the right edge n = (+1, 0): an inward flux makes ∂T/∂x > 0 there, so qb > 0 — while the flux vector component qx = −k ∂T/∂x is negative. Two different symbols; keep them apart.

Why

Insulated = adiabatic = zero normal flux. It is a Neumann condition with qb = 0, not a Dirichlet condition.

Students lose marks on signs here. The rule: write the outward normal, then apply (2.15): q_b = k dT/dn. Heat entering through the right edge flows in the −x direction, so q_x = −k dT/dx < 0, hence dT/dx > 0 and q_b = k dT/dx × (+1) > 0. So q_b (the boundary flux of (2.15)) is positive for an inward flux; the flux-vector component q_x is negative. Next session this is why an inward flux is a positive load in {b}. Lecturer note: the text’s (2.41) writes the components with the opposite sign to (2.15); teach (2.15). The worked example avoids the issue by having only insulated and Dirichlet edges.
