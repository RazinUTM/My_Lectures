Block 4 · the same functions inside commercial code

ANSYS’s four-node element uses these N₁ … N₄

Same functions, new coordinates

ξ = 2x/a − 1 and η = 2y/b − 1 map 0 ≤ x ≤ a, 0 ≤ y ≤ b onto −1 ≤ ξ, η ≤ 1, and

N₁ = ¼(1 − ξ)(1 − η) = (a − x)(b − y)/ab

which is the text’s (2.21). The other three follow by changing signs.

Check

Each surface is 1 at its own corner, 0 at the other three and straight along every edge: the three checks on the next slide.

Why

Plane Stress Part 2: the square lets one formula serve any four-sided element — the isoparametric idea behind PLANE182.
