Block 1 · the same PDE in a real simulation

A heated plate under a channel flow

Why

The solid plate obeys today’s conduction PDE (with ∂T/∂t kept; at steady state it is exactly {∂}[E]{∂}ᵀT = −qh), with T fixed on its heated bottom face.

Check

At the interface the solid receives a temperature from the fluid code and returns a heat flux: one Dirichlet and one Neumann condition, as in Block 3.

Use this slide to show that the PDE of today is not a textbook toy: in a coupled heat-transfer analysis the solid side is exactly our 2D conduction problem, solved by an FE code, while a CFD code solves the fluid. Ask: which boundary of the plate is Dirichlet (the heated bottom, T fixed), which is Neumann (the interface, where the solid hands a heat flux to the fluid), and which edges are insulated (the two short sides).
