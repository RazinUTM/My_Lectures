Professional Habit 3

Check the table before you use it

ΣM = 0

At every joint the end moments add up to zero (with the columns, in Unit 4).

M = 0 at a pin

A released end carries no moment. Frame S3, line 8: MA = −59.25.

VL + VR = wL

In every span; and the span moment is below wL²/8.

Then design

Only a table that passes all three goes into the beam and column design.
