# SEAA 4333 Reinforced Concrete Design II

Faculty of Civil Engineering, Universiti Teknologi Malaysia. Semester 1, 2026/27 (12 October 2026 to
24 January 2027). Five topics in fourteen Units, designed to Eurocode 2: staircases, frame analysis,
columns, foundations and retaining walls.

Website: <https://razinutm.github.io/My_Lectures/SEAA4333-RCD2/>

Each Unit page is built on the lecturer's T&L app template: a header with breadcrumbs, search, Short notes
and the settings buttons (BM/EN · theme · text size · screen guide); seven tabs (Start with the plan before,

lists the terms and the everyday Malay words that stay Malay). The printed workbook stays the book students

## Build

From a Unit folder: `./build.sh` (needs Python 3 with Pillow, beautifulsoup4 and lxml, and Node; the
script installs MathJax into `web/node_modules/` on first run). The course home: `python3 shared/build_home.py`.
Open the pages through a local server (`python3 -m http.server` in `My_Lectures/`) so that the slides, the
Explorer and Dr RJ's manifest load.

## Privacy

Progress, preferences, the Staircase Lab's class table and the answers in the Frame, Column, Foundation and Retaining Wall Labs are kept in the student's own browser (localStorage);
the course home can export and import them. Dr RJ points to sections of the page. When the AI tutor is
switched on (the switch `AI_SEAA4333` of the rz-tutor Worker), his panel shows a notice first, and the questions a
student then types go through the Worker to the Claude API (Anthropic) to be answered from the Unit's own text;
the Worker keeps counts (questions, the sections he points to, modes), never the questions or the answers. With the
switch off nothing typed leaves the browser. The model is Claude Haiku 5.5 (Anthropic), reached through rz-tutor-worker
0.4.1 (app `seaa4333`, registered 23 Nov 2026); Dr RJ answers only from the Unit's own text and can be wrong. Graded work stays in UTM eLearning.
